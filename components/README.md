# Componentes reutilizáveis

Copie os blocos desta pasta para as landing pages conforme necessário.

- `tally-embed.html`: formulário Tally incorporado;
- `whatsapp-button.html`: botão direto para WhatsApp;
- `faq.html`: seção básica de perguntas frequentes.

Antes de publicar, substitua todos os textos entre `{{CHAVES}}`.
