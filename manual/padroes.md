# Padrões do LP Lab

## Repositórios

- `lp-nome-do-negocio`: landing page
- `site-nome-do-negocio`: site com múltiplas páginas
- `arquivo-nome-do-projeto`: projeto encerrado, mantido apenas como referência

## Branches

- `main`: versão publicada ou aprovada
- `dev`: opcional, para alterações ainda não aprovadas

## Commits

Use mensagens simples:

- `Cria estrutura inicial`
- `Atualiza textos da seção principal`
- `Adiciona formulário Tally`
- `Ajusta versão mobile`
- `Publica versão aprovada`

## Segurança

Nunca versionar:

- senhas;
- tokens de API;
- arquivos `.env`;
- dados pessoais desnecessários;
- planilhas de contatos de clientes.
