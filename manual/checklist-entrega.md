# Checklist de entrega ao responsável

- [ ] Aprovação final registrada
- [ ] Repositório sem arquivos pessoais ou credenciais
- [ ] Senhas e tokens não estão no código
- [ ] Domínio e DNS documentados
- [ ] Formulários pertencem ao responsável ou têm plano de transferência
- [ ] Repositório transferido ou responsável adicionado
- [ ] GitHub Pages verificado após a transferência
- [ ] README atualizado com instruções de manutenção
- [ ] Cópia local arquivada conforme combinado
